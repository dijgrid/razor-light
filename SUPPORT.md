# Support

Use the repository's GitHub issue forms for reproducible bugs, feature proposals, and focused usage
questions.

Before opening an issue:

1. Search existing issues, including historical issues in the
   [upstream repository](https://github.com/toddams/RazorLight/issues).
2. Reduce the problem to a minimal project or template.
3. Include the RazorLight package version, target framework, SDK version, operating system, and
   complete exception details.

This is a community-maintained project and does not provide a guaranteed response time or
commercial support. Security reports must follow [SECURITY.md](SECURITY.md) and must not be posted
as public issues.
