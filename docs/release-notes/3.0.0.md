# RazorLight 3.0.0

RazorLight 3.0.0 is the first stable release of the independently maintained line. It requires
**.NET 10** and uses the `Dijgrid.RazorLight` package identity. Core RazorLight renders generic
plain text by default; install `Dijgrid.RazorLight.Html` and call `UseHtmlEncoding()` when HTML
expression encoding is required.

Read the [2.3.1-to-3.0 migration guide](https://github.com/dijgrid/razor-light/blob/master/docs/migration-3.0.md)
before upgrading. This remains a major-version compatibility reset: MVC tag helpers and obsolete
inherited APIs are not part of the supported 3.0 surface.

## Highlights

- Render strings, files, embedded resources, and custom projects with dynamic or strongly typed
  models; compose trusted template helpers with `AddCSharpSource` and `@compileSource`.
- Reuse compiled templates safely, invalidate coherently, and run a supported precompiled-only mode
  without constructing the runtime compiler graph.
- Use cancellation through lookup, compilation, layouts, includes, rendering, and caller-owned
  writers. Deployment diagnostics identify unsupported trimming and Native AOT paths.
- The public builder is sealed and its supported customization points are explicit: projects,
  caching providers, output encoders, and page initializers. XML documentation is enforced for new
  exported APIs.
- The manual includes executable developer-documentation tests. A reproducible scaling harness
  covers 5-15 MiB templates and 1,000-template workloads.
- String-returning renders use cleared pooled character storage, cutting cached large-output managed
  allocation by roughly half. Use the `TextWriter` render overload when a result string is not
  required.

See the [3.0.0 changelog](https://github.com/dijgrid/razor-light/blob/master/CHANGELOG.md) and the
[performance and memory scaling evaluation](https://github.com/dijgrid/razor-light/blob/master/benchmarks/scaling-2026-08-10.md)
for details.
