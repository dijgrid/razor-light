# RazorLight 3.0.1

RazorLight 3.0.1 makes runtime compilation failures actionable in normal production builds. Roslyn
diagnostics now include their message text without requiring `EnableDebugMode()`, so errors identify
the missing, ambiguous, or invalid symbol instead of reporting only a diagnostic ID.

Mapped template paths, generated source, missing-template keys, and known-key inventories remain
redacted unless debug mode is explicitly enabled. Applications that forward authoring failures
across a trust boundary can set `RazorLightOptions.RedactCompilerDiagnosticMessages` to preserve the
previous ID-only compiler-message policy independently of debug mode.

This is a backward-compatible patch release for the `Dijgrid.RazorLight`,
`Dijgrid.RazorLight.Html`, and `Dijgrid.RazorLight.Precompile` packages. It requires **.NET 10**.

See the [3.0.1 changelog](https://github.com/dijgrid/razor-light/blob/master/CHANGELOG.md) and the
[template security guide](https://github.com/dijgrid/razor-light/blob/master/docs/template-security.md)
for details.
