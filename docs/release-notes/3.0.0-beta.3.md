# RazorLight 3.0.0-beta.3

This is the first publishable beta of the independently maintained RazorLight 3.0 line. It requires
**.NET 10** and uses the new `Dijgrid.RazorLight` package ID. RazorLight defaults to generic
plain-text output; HTML encoding is available through the optional `Dijgrid.RazorLight.Html` package
and `UseHtmlEncoding()`. MVC tag helpers are no longer included, and intentionally obsolete public
APIs were removed before the 3.0 compatibility boundary is frozen.

The package and release workflow now validate reviewed artifacts correctly after protected-environment
approval. Earlier `beta.1` and `beta.2` tags did not publish NuGet packages.

Read the complete [2.3.1-to-3.0 migration guide](https://github.com/dijgrid/razor-light/blob/master/docs/migration-3.0.md)
before upgrading.

## Highlights

- Render strings, files, embedded resources, and custom projects with dynamic or strongly typed models.
- Compose templates with reviewed ordinary C# source through `AddCSharpSource` and `@compileSource`.
- Use cooperative cancellation throughout lookup, compilation, rendering, layouts, and includes.
- Compile once and render repeatedly with explicit reusable-template lifecycle semantics.
- Run a supported precompiled-only mode without constructing or loading the runtime compiler graph.
- Use coherent invalidation, deterministic artifact identities, portable symbols, and redacted
  production diagnostics.
- Deploy framework-dependent, self-contained, and supported single-file configurations with explicit
  trimming and Native AOT diagnostics.

This is a beta intended for migration testing and API feedback. It must not be promoted to a stable
3.0 release without a separate maintainer review and approval.
